# 🎵 ZapTone - Decentralized Music Platform

ZapTone is a cutting-edge, decentralized music platform built on the Nostr protocol. It empowers artists to share their music directly with fans while enabling listeners to discover, enjoy, and support musicians through Bitcoin Lightning payments.

## 🌟 Features

### 🎶 Core Music Features
- **Music Upload & Streaming**: Artists can upload high-quality audio files to Blossom servers
- **Album Creation**: Organize tracks into albums with custom artwork and metadata
- **Playlist Management**: Create and share custom playlists
- **Audio Player**: Full-featured music player with play/pause, skip, volume control, and queue management
- **Search & Discovery**: Advanced search with genre filtering and tag-based discovery

### 🌐 Decentralized Architecture
- **Nostr Integration**: Login and authentication via Nostr keys
- **Blossom Storage**: Decentralized file storage for music and artwork
- **Custom NIPs**: Extended Nostr protocol for music-specific features
  - Kind 31808: Music Tracks
  - Kind 31809: Music Albums
  - Kind 31810: Music Playlists

### ⚡ Social & Economic Features
- **Lightning Integration**: Zap (tip) artists directly with Bitcoin
- **Social Engagement**: Like, comment, and share tracks
- **Artist Profiles**: Comprehensive artist pages with bio, discography, and stats
- **Real-time Interactions**: Live comments and reactions

### 🎨 Modern Design
- **Purple Gradient Theme**: Beautiful, music-focused design inspired by Spotify
- **Dark/Light Mode**: Complete theme system
- **Responsive Layout**: Works perfectly on desktop and mobile
- **Inter Font**: Clean, modern typography throughout

## 🚀 Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: TailwindCSS with custom music theme
- **UI Components**: shadcn/ui component library
- **State Management**: TanStack Query for data management
- **Audio**: Howler.js for audio playback
- **Nostr**: @nostrify/nostrify for protocol implementation
- **Build Tool**: Vite for fast development and building
